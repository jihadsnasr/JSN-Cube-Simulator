# JSN-Cube-Simulator

A simple 2D Rubik's Cube simulator built with C# and Windows Forms. It simulates a standard 3x3x3 Rubik's Cube using a 2D interface.

Installation

Download or clone this repository.

Open the project folder.

Run setup.exe to install the application.

Follow the installation instructions.

Launch JSN-Cube-Simulator after the installation is complete.

Requirements

Windows

.NET Framework or other required runtime, if prompted by the installer

About

This project was created to simulate a 3x3x3 Rubik's Cube through a simple 2D interface.
